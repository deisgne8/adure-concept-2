# ADURE — Aysha Concept

Static homepage concept for ADURE, imported from “Adure homepage concept 5.zip”.

## Run locally

From this directory, run:

```sh
python3 -m http.server 5185 --bind 127.0.0.1
```

Then open http://127.0.0.1:5185. No build step is required.

The page uses Google Fonts and the Tailwind CDN, so an internet connection is needed for those resources.
